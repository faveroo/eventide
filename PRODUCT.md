# Eventide

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Equipes de desenvolvimento que monitoram aplicações, APIs e workers de suas organizações.

## Product Purpose
Detectar falhas, correlacionar eventos e apoiar a investigação e resolução de incidentes.

## Stack
Laravel 13, PHP 8.3+, React 19, Inertia 3, TypeScript e Tailwind 4. Filas e scheduler Laravel.

## Capabilities and Constraints
O README é a fonte do escopo: organizações e membros, projetos, health checks, eventos autenticados, integração GitHub, regras de detecção e incidentes correlacionados. Cada organização é isolada por autorização. SDK é explicitamente futuro no README. Serviços externos dependem de configuração pelo operador.

## Brand Commitments
Eventide. Detect. Correlate. Respond. Interface em português, preservando identificadores técnicos de eventos.

## Evidence on Hand
README.md e implementação existente. O usuário autorizou completar backend e frontend com frontend-design, taste-skill e impeccable. Escopo adicional externo ao repositório ainda não informado; implementação segue o README por inferência explícita.
